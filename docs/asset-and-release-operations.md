# Asset and Release Operations

[日本語](asset-and-release-operations-ja.md)

AIKernel.Doom is published as a source demo. It is not a package and it does
not vendor WAD or model runtime assets. The public 0.1.2 Web demo does include
the generated `doom.wasm` artifact because the hosted demo redistributes that
GPL-derived runtime binary with corresponding source materials.

This policy follows the AIKernel guideline boundary between source contracts,
Provider-owned runtime artifacts, and deployment operations. The repository
must remain auditable without embedding large or third-party binary payloads.

## Version

Current demo version:

```text
0.1.2
```

The demo remains non-packaged, and its AIKernel package references are aligned
with the official NuGet canonical package line v0.1.2. Local development
package paths should not be used by default in this repository.

## Source Assets

Committed source assets include:

- C# provider, capability, demo, and optimizer code,
- C/Emscripten overlay code,
- JavaScript browser runtime code,
- HTML terms and license notice source,
- ROM metadata sample,
- autoplay profile source JSON,
- public 0.1.2 `doom.wasm` artifact plus `/demo/doom/module.json`,
- documentation.

## External Runtime Assets

Do not commit:

- `DOOM1.WAD`,
- commercial DOOM WADs,
- Bonsai GGUF files,
- browser cache data,
- optimizer telemetry artifacts.

Public deployments may host runtime files separately only when the deployment
operator has confirmed license and redistribution requirements.

## Required Hosted Files

The public Web runtime expects these paths when deployed:

```text
/demo/doom/module.json
/demo/doom/doom.rom
/demo/doom/doom.wasm
/demo/doom/DOOM1.WAD
/models/bonsai1.7b/manifest.json
/models/bonsai1.7b/Bonsai-1.7B-Q1_0.gguf
/models/bonsai1.7b/LICENSE
/models/bonsai1.7b/NOTICE.txt
```

The repository contains the public 0.1.2 `doom.wasm` artifact and
`module.json`. WAD and model files remain external hosted assets.

## Consent Requirements

The runtime prompt must remain suspended before protected downloads. Consent
text should describe:

- hosted WAD download/cache/load,
- hosted model download/cache/load,
- `doom.wasm` runtime load,
- total expected download/cache size,
- license and notice links,
- reject behavior.

Any change to hosted files should update:

- manifest file size,
- checksum,
- license path,
- notice path,
- consent size estimate,
- terms and license page.

## GPL Corresponding Source for doom.wasm

`doom.wasm` is derived from GPL-covered doomgeneric source. When a public
deployment hosts this compiled artifact, the corresponding source must remain
available with the same release surface:

- the pinned doomgeneric checkout used for the build;
- AIKernel overlay files in `src/DoomWasm.Native/src`, including
  `aik_doom_sound.c` for the native SFX audio bridge;
- `src/DoomWasm.Native/build.ps1`, `build.sh`, and `Makefile`;
- `src/DoomWasm.Native/patches/doomgeneric-aikernel.patch`;
- `src/DoomWasm.Native/patches/doomgeneric-upstream.patch`;
- upstream copyright notices and GPL license text.

The deployment manifest at `/demo/doom/module.json` should identify the
doomgeneric commit, source location, patch file, overlay files, generated wasm
size, and generated wasm checksum.

Consent is a runtime governance boundary. Treat it as part of the Provider
contract, not as page copy.

## Deployment Checklist

Before publishing a web mirror:

- [ ] Build or copy source web assets from `src/DoomWeb/wwwroot`.
- [ ] Verify the committed `doom.wasm` was generated by Emscripten and matches
      `/demo/doom/module.json`.
- [ ] Host shareware or user-provided WAD through an approved process.
- [ ] Host Bonsai model files and notices outside the source repository.
- [ ] Validate model `sizeBytes` and `sha256`.
- [ ] Validate WAD checksum and manifest.
- [ ] Confirm `terms-and-licenses.html` matches the actual hosted files.
- [ ] Confirm no WAD, model, browser cache, or telemetry artifact is committed.
- [ ] Run `doom.status`, `doom.phase.check`, and `copy.logs` on the deployed
      page.

## Git Hygiene

AIKernel.Doom is a nested git repository. Commit source changes from the
`AIKernel.Doom` repository root.

The broader workspace can include WebSite mirror changes, generated blog files,
or hosted runtime assets. Those should not be mixed into the AIKernel.Doom
source commit unless explicitly intended.
