Runtime Consent

The AIKernel.Doom demo remains suspended until the user explicitly approves by typing yes.

Approval allows this deployment to download, cache, load, validate, and use the configured runtime files, including:

  • the hosted shareware DOOM1.WAD asset
  • the hosted Bonsai-1.7B-Q1_0.gguf model file
  • the doom.wasm runtime artifact
  • related manifests, notices, and demo metadata

The Bonsai-1.7B-Q1_0.gguf model file is redistributed by this deployment from the upstream Hugging Face model repository identified in the model manifest.

The expected protected download/cache size for this deployment is approximately 253 MB for the core hosted runtime files, or approximately 270 MB when auxiliary model metadata in this deployment is included. This is under 300 MB in the current deployment.

The exact transferred size can vary depending on browser cache state, compression, model file size, WAD file size, WASM artifact size, manifest size, notice files, and deployment configuration.

No download or loading of hosted WAD data, model files, or other large runtime assets is started before explicit approval.

Rejecting the prompt, closing the prompt, or entering anything other than an accepted confirmation keeps the DOOM runtime suspended and prevents the protected download/load sequence.
